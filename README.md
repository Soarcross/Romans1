# Romans 1: The Power of God for Salvation

A single-file HTML slideshow for a discussion-based Bible study on Romans 1 (9 sections, about 65 minutes).

Open `index.html` in any browser. No install needed.

## Controls
| Key | Action |
| --- | --- |
| → / Space / click | Next slide (click the left quarter of the screen to go back) |
| ← | Previous slide |
| Swipe | Next or previous (phone/tablet) |
| N | Toggle presenter notes |
| T | Toggle section countdown timer |
| P / R | Pause or reset the current section timer |
| 1–9 | Jump to a section |
| F | Fullscreen |
| E | Edit text in place (Ctrl+S downloads an edited copy) |
